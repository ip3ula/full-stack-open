# Full Stack Open 2025 – My Solutions

This repository contains my personal solutions to the exercises in the [Full Stack Open 2025](https://fullstackopen.com/en/) course by the University of Helsinki. The course covers modern full-stack web development with JavaScript, focusing on practical skills and real-world applications.

## 📘 About the Course

Full Stack Open is one of the most respected free web development courses available. It teaches you how to build full-stack applications using React for the frontend and Node.js with Express and MongoDB for the backend. It also introduces GraphQL, TypeScript, React Native, CI/CD, and containerization with Docker.

## 🚀 What I Learned

- Building single-page apps with **React**
- Managing state with **Hooks** and **Redux**
- Creating backend APIs with **Node.js** and **Express**
- Storing data with **MongoDB** & **Mongoose**
- Testing with **Jest**, **React Testing Library**, and **Supertest**
- Using **TypeScript** and **GraphQL**
- CI/CD pipelines with   **GitHub Actions**
- Deploying full-stack apps to services like **Render**, **Vercel**, or **Fly.io**
- Dockerizing applications for development and production
- Building mobile apps with **React Native**
